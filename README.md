# Hyperreality Engine / SyncStrike

Early Godot rollback multiplayer experiments with Gemini-assisted gameplay configuration.

Current demo: SyncStrike QA Benchmark Demo — Gemini Rollback Fighter.

## What This Proves

- Rollback networking works across two computers
- Gemini can generate fighting-game move data
- The generated move can enter a deterministic rollback simulation

## Quick Start

1. Install Godot 4.x
2. Clone this repo
3. Open `project.godot`
4. Run the demo scene

Full setup guide: [docs/SETUP.md](docs/SETUP.md)
